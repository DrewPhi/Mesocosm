without the `_v3` suffix and with `_v2`, respectively.

```bash

```

To replay, copy a complete `latest.sqlite` checkpoint to a local run directory as
`world.sqlite`, then use `python3 -m eden replay --run <directory>`. Avoid opening
the rolling archive as a writable live SQLite database on shared storage. An offline
analysis connection to a standalone archived snapshot should use SQLite's immutable
read-only mode; the live database must not use immutable mode.

Readiness: the runtime, model transport, persistence, live socket integration, and
bounded trial execution have been exercised. Useful autonomous long-horizon behavior
and real-model physical adjudication still require observation. These first runs
already show that syntactically valid model output can produce unproductive behavior.
